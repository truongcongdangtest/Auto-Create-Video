# Avatar Assets

Placeholder geometric SVG avatars for VietViral host overlay (Phase 03).
Generated for the project, no third-party rights asserted. Free to replace
with commissioned/AI-gen artwork.

Files:
- `alice.svg` / `alice-mouth.svg` — feminine, warm tones
- `minh.svg` / `minh-mouth.svg` — masculine, suit/business
- `linh.svg` / `linh-mouth.svg` — feminine, business
- `huy.svg` / `huy-mouth.svg` — masculine, casual
- `mai.svg` / `mai-mouth.svg` — feminine, dynamic
- `neutral.svg` / `neutral-mouth.svg` — robot, gender-neutral

Each `<id>.svg` is the closed-mouth face (256×256). The `<id>-mouth.svg` is
a small overlay (100×50) rendered absolute over the face's mouth region;
opacity is toggled to 1 when host-overlay.html's inline JS detects voice
RMS above threshold.
