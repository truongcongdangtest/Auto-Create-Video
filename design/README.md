# Auto-Create-Video — Desktop App Mockups

Five distinct design directions for the main create-video workspace. Each is a single self-contained HTML file (Tailwind CDN + Google Fonts, no build step) with realistic Vietnamese sample data and the full UI surface: input area, voice/channel pickers, 8-step pipeline progress, project queue, preview pane, settings access, and footer cost indicator.

## How to view

Double-click any `.html` file to open it in your default browser, or drag-drop into Chrome/Edge. Designs are tuned for a 1920×1080 viewport. No internet-blocked assets — everything loads from CDN.

## The five directions

1. **`mockup-01-linear-minimal.html`** — Linear / Notion / Raycast. Light theme, slate + indigo accent, Inter type, hotkey label on every action. Keyboard-first, calm, editorial whitespace. For the user who lives in `⌘K`.

2. **`mockup-02-creator-studio.html`** — CapCut / Descript / Riverside. Warm dark slate-900 with violet undertones, rounded 14-16px corners, drag-and-drop hint zones, colorful gradient CTAs. Friendly, "let's make a video" energy. For the social-first creator.

3. **`mockup-03-pro-editor.html`** — DaVinci Resolve / Premiere Pro. Dense zinc-950 multi-panel layout (navigator | viewer | inspector | timeline), 12px text, NVENC/FPS/VRAM scopes, pipeline as a true timeline with playhead. For the power user batching 20 videos/day.

4. **`mockup-04-cyber-ai.html`** — Runway / Pika / Krea / Suno. Glassmorphic over animated cyan↔magenta aurora background, holographic borders, Geist Mono module headers, neon-glow CTAs, subtle CSS particles. Feels like an AI lab. For impact-first marketing screenshots.

5. **`mockup-05-vietviet-warm.html`** — Vietnamese-native warm creator (Vietcetera / fpt.shop / Maika Mộc vibes). Cream paper base, lacquer-red + antique gold accents, Lora italic display + Be Vietnam Pro body, lotus motif texture, vietnamese-style metric formatting (`11,42$`, `92.000.000đ`). A tool made by a VN creator for VN creators.
